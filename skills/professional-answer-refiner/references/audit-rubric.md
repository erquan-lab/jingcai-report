# 论断分级判定细则（Audit Rubric）

本文件定义四类证据状态如何判定、来源如何归属、以及最常见的逻辑陷阱。SKILL.md Step 2/3 时按此执行。

## 四类证据状态定义

### 已确认事实
- **判定标准**：有可复现来源（官方口径、法规条文、权威数据库、可验证数据）或可通过计算/交叉验证复现。同一结论在 ≥2 个独立信源一致。
- **输出写法**：直接陈述，后附来源。
- **例子**："某药说明书的用法用量为 X 次/日"（以说明书为准）；"2024 年某省 GDP 为 X 亿元"（附统计口径与来源）。

### 合理推断
- **判定标准**：从已确认事实出发，经可展示的推理链得出；推理的每一步前提都成立，结论不超出前提。
- **输出写法**：明确给出推理链："由 A、B 可推出 C"，并说明如果 A 或 B 不成立则结论失效。
- **例子**："由于历史数据连续 5 年下降且政策未变，可合理推断明年维持下行趋势（推断，非预测保证）。"

### 个人建议
- **判定标准**：基于经验、偏好、立场或资源的取舍，不是事实主张；不同专业人士可能给出不同建议。
- **输出写法**：标注"（建议）"，写清适用场景、行动步骤、完成标准、失败条件。
- **例子**："对现金流紧张的初创团队，建议优先做 A 而非 B（个人建议，取决于你更看重速度还是质量）。"

### 无法确认
- **判定标准**：当前无法取得可靠证据；或证据互相矛盾无法裁决；或数据过时无法验证；或结论依赖用户未提供的私有信息。
- **输出写法**：放入"待核实项"，逐条说明"为什么无法确认"和"通过什么途径可以核实"。
- **例子**："该公司最新营收数据未公开披露，无法确认（可查年报/监管公告核实）。"

## 来源归属规则

- **可追溯**：来自官方文档、权威媒体、数据库、可访问网页 → 标注来源（链接/标题/发布机构/日期）。
- **一方称**：仅来自单一当事人、单一平台、无法独立验证 → 标注"一方称"，不当作普遍事实。
- **无法核实**：找不到来源或来源不可访问 → 归入"无法确认"，禁止编造。

## 常见逻辑陷阱（逐条排查）

1. **数据过时**：结论基于旧数据，未检查时效 → 需核对数据时间，超期标注。
2. **样本偏差**：以个别案例/小样本推出普遍结论 → 检查样本范围与代表性。
3. **单一信源**：只依赖一个来源 → 需要第二个独立信源交叉验证。
4. **幸存者偏差**：只看到成功者，忽略失败样本 → 补看失败样本与对照组。
5. **相关当因果**：两变量相关 ≠ 存在因果 → 需识别混淆变量与因果方向。
6. **个别当普遍**：特例被推广为规律 → 检查结论适用范围。
7. **确定词滥用**："必然/一定/专家一致认为/研究表明" → 凡无完整证据链，一律降级为推断或建议。
8. **偷换概念**：结论中的概念与前提中的概念不一致 → 核对术语前后一致性。

## 判定优先级

- 证据状态之间冲突时，按"已确认事实 > 合理推断 > 个人建议 > 无法确认"的优先级降级处理，宁降级不夸大为事实。
- 一条论断既含事实又含推断时，拆分表述，分别标注，不混为一谈。
